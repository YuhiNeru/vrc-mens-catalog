# VRCFinderを参考にした収集・設計方針

2026-10-07、ユーザー指定の [メンズ検索](https://vrcfinder.net/ja/search/?q=%E3%83%A1%E3%83%B3%E3%82%BA)、[モデル一覧](https://vrcfinder.net/ja/model/)、[水瀬ページ](https://vrcfinder.net/ja/model/minase/)、[凛仁ページ](https://vrcfinder.net/ja/model/licht/) を確認した。

## 収集範囲に反映する点

- 現在の8体以外にも男性向けのモデルがある。次回の本体確認候補として墨惺・カルネ・怜・凛仁と、共通素体の確認候補として+Headを登録した。`config/expansion-candidates.json` に参考URLと未確認の候補商品IDを保存。商品IDは参照画像URLからの候補値であり、正式なBOOTH商品本文の確認を経てからカタログへ取り込む。
- 衣装が女性アバターにも対応している場合でも、登録済み男性アバター用の販売対象版を確認できれば掲載する。現在の購入バリエーション照合もこの条件で動く。メンズという検索語や商品名だけでは対応確定しない。
- 衣装・髪型・アクセサリー・テクスチャなどは取得範囲を分ける。現在の全ページ収集は3D衣装カテゴリ。別カテゴリは次のバッチでページ数・重複・新規件数を測定し、衣装の完了予想とは別に予算を組む。
- VRCFinderは水瀬を「販売終了」と表示し、対応アイテムの検索を残している。本体の販売状態と、所有済みアバターに使える衣装の対応情報を分ける設計を参考にする。こちらで確認できたBOOTH本体404だけから販売終了を確定しない。現在の本体入手可能条件を変更する際は、履歴・根拠・表示文言も設計する。

## 検索導線に反映する点

対応モデルを起点に、商品カテゴリ・衣装タイプ・テイスト・カラー・価格・無料で探せる構造を参考にする。現在実装済みなのはアバター、服の種類、テイスト、価格、並び順。カラー、機能、対応環境などを追加する場合は、作者の明示情報と推定分類の根拠を区別する。

男性向けカタログでは、各対応版の価格、完全対応・セミ対応・変換前提、共通素体の条件を商品カードから確認できる導線を維持する。次の追加範囲は本体確認を先に行い、アバター別・カテゴリ別にクロール計画を作る。

## 現在の実行との関係

進行中の8体・10検索・91ページの計画収集は継続中。今回の参考調査は追加候補の登録と設計方針の記録であり、未確認モデルの公開や追加カテゴリの一括取得はまだ実行していない。BOOTHを商品・価格・画像・対応判定の確認先とする。画像は引き続きBOOTHの元URLを直接表示する。
